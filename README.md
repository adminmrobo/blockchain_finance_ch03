# 블록체인 편 3장 「비트코인」

연구실 해설 대시보드 시리즈의 블록체인 편 셋째이자 마지막 장입니다. 박사·하루(조수)·초파리 연구원·주판봇이 진행하는 인터랙티브 해설 페이지 7편과 목차로 이루어져 있습니다. 2장 「블록체인 기술」이 장부를 지키는 기술이었다면, 3장은 그 장부 위의 돈인 비트코인을 다룹니다. 합의 방식, 채굴장, 반감기, 거래의 모양, 익명성, 화폐성, 범죄 악용과 추적의 일곱 편입니다.

## 보는 법
- `index.html`을 브라우저로 열면 목차가 나옵니다. 설치나 서버가 필요 없습니다.
- GitHub Pages로 공개하려면 저장소 설정에서 Pages를 켜고 루트(`/`)를 고르면 됩니다.
- 외부 요청은 글꼴(Google Fonts) 하나뿐이고, 브라우저 저장소는 쓰지 않습니다.
- 3-06은 화폐성에 대한 두 견해를 함께 소개하며, 투자 판단을 다루지 않습니다. 3-07은 추적의 원리를 모형으로 보여 주며, 추적을 피하는 방법을 다루지 않습니다.
